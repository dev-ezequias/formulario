Utilize HTML + CSS + JavaScript para construir uma pequena página Web interativa.
A página deverá conter:
Uma estrutura HTML organizada.
Estilos CSS básicos.
Pelo menos uma variável e uma função JavaScript.
Um botão com evento de clique.
Alguma alteração no conteúdo da página.
Um formulário ou campo de entrada.
Uma validação ou cálculo realizado com JavaScript.
Publicar no Github, disponibilizar o link ou enviar o arquivo compactado.
